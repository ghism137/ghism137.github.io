# ghism137.github.io

Portfolio cá nhân của **Trần Thái Hưng (ghism)** — giao diện "quant terminal", có chế độ sáng/tối và song ngữ Việt/Anh.

🔗 **https://ghism137.github.io**

- HTML/CSS/JS thuần, không build step
- Hero: cây khung nhỏ nhất (MST) chạy trực tiếp bằng thuật toán Prim $O(n^2)$ mỗi khung hình — con trỏ chuột cũng là một đỉnh
- Công thức hiển thị bằng KaTeX (vendored trong `vendor/`)
- Con vịt cao su ở góc màn hình: bấm vào để được tư vấn debug 🦆

Chạy local: `python -m http.server` rồi mở http://localhost:8000
