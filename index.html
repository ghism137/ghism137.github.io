$LAWRAG

Vietnamese Labor-Law AI Agent

active · capstone

A RAG agent for workers and HR: answers labor-law questions with article-level citations, calculates severance, probation pay, unemployment insurance and annual leave with deterministic Python (the LLM only extracts parameters), and drafts legal forms from Jinja2 templates.

  • Corpus: Labor Code 2019, Social Insurance, Employment law, decrees & circulars → chunked by article
  • Hybrid retrieval: sparse BM25 + dense BGE-M3 on Qdrant
  • Design rule: no LLM arithmetic → no hallucinated money

$FRAUD

IEEE-CIS Fraud Detection

AUC-PR 0.504 ▲

A leakage-proof fraud pipeline on 590k card transactions with only 3.5% fraud. Purged chronological split (14-day gap for chargeback delay), 337 engineered features, 8 models compared, and a threshold chosen by business cost instead of 0.5.

  • Velocity features with shift(1).expanding() → a transaction never sees itself
  • Correlation grouping 339 → 235 V-features instead of PCA (which destroyed signal)
  • SHAP for explanations, dollar-weighted AUC-PR for high-value fraud
0.504AUC-PR (random = 0.035)
14.3×lift over random
0.906AUC-ROC
−$8.9kcost at t* = 0.365 vs 0.5

$MST

Stock Clusters via Minimum Spanning Tree

applied algorithms

Econophysics à la Mantegna (1999): log returns → Pearson correlations → a real metric → an MST that keeps the N−1 strongest links of the market. Prim and Kruskal (with Union-Find) are written by hand; NetworkX is only used to cross-check.

  • Clusters vs. GICS sectors measured by ARI / NMI, k-means as baseline
  • Permutation test: is the tree real structure or noise?
  • Rolling MST + Random Matrix Theory to watch correlation breakdown in 2020 and 2022
N−1edges kept from N(N−1)/2
O(N²)Prim on a dense graph
ARI/NMIvs. real sectors
p-valuepermutation test

$SAR

Oil Spill SAR Segmentation

team · deep learning

Finding oil slicks on the sea surface in radar (SAR) images. Three segmentation models trained under one shared interface, combined by averaging probability maps, and served in a Streamlit app: upload → pick a model → mask and overlay.

  • Unified load_model / predict API so any model plugs into the app
  • Ensemble by average probability or 2-of-3 majority vote
  • Same metrics for every model: Dice, IoU, Precision, Recall
